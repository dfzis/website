# web

mewzah's personal site. plain html/css, no build step.

- links: the `socials` list in `index.html`
- avatar: `assets/avatar.jpg`
- music: drop an mp3 at `assets/song.mp3` and set the title in `index.html`. the player stays hidden until that file exists.

background: "Sea sky and clouds, Ibiza, Spain" by José Lodos Benavente, CC0, via Wikimedia Commons.
