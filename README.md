# web

xv's personal site.

## assets

drop a frutiger-aero / y2k backdrop photo at:

    assets/backdrop.jpg

it's used as the full-page background (sky + clouds + hills in one image).
recommended ~2400×1600, landscape, jpg or webp (rename the css url accordingly
if you use a different extension). if the file is missing, the page falls back
to a css gradient sky.
